# uib_resources

Resources for static UIB demo - static assets and sample data accessible via direct URLs.

## Usage

All resources in this repository can be accessed directly via GitHub raw URLs using the following pattern:

```
https://raw.githubusercontent.com/bonitasoft-presales/uib_resources/main/<path-to-file>
```

### Examples

**Logo:**
```
https://raw.githubusercontent.com/bonitasoft-presales/uib_resources/main/logo/logo-cnaf.jpg
```

**Sample Product Data:**
```
https://raw.githubusercontent.com/bonitasoft-presales/uib_resources/main/sample-data/telecom-products.json
```

## Available Resources

### Logos
- `logo/logo-cnaf.jpg` - CNAF brand logo

### Sample Data
- `sample-data/telecom-products.json` - Telecom products and services catalog (hardware, software, and services)
